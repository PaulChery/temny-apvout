Privacy Policy — Temny Apvout Uploader

Last updated: 15 November 2026

Temny Apvout Uploader (“the app”) is a personal command-line tool used only by the owner of the YouTube channel “Тёмный Апвоут” to upload and manage videos on that channel through the YouTube Data API v3.

Data the app accesses

  • With the owner’s consent through Google OAuth, the app receives an access token for the scopes youtube.upload and youtube.force-ssl.
  • It reads the owner’s channel title and playlists, and uploads the owner’s own video files with their titles, descriptions, tags, thumbnails, captions, playlist placement and publishing times.
  • It does not access other users’ data, comments, subscribers, analytics, contacts, email or any personal information beyond what is needed for these uploads.

How data is stored

The OAuth token and the IDs of uploaded videos are stored only on the owner’s own computer. Nothing is sent to any server other than Google’s APIs. No data is sold, shared with third parties, used for advertising or used to train AI models.

YouTube API Services

The app uses YouTube API Services. By using the app you agree to be bound by the YouTube Terms of Service. Google’s privacy practices are described in the Google Privacy Policy (http://www.google.com/policies/privacy). The app does not use cookies, device identifiers or any tracking; it stores no information on users’ devices other than the owner’s own OAuth token file.

Google API Services

The app’s use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; by using it you also agree to the YouTube Terms of Service, and Google’s handling of data is described in the Google Privacy Policy.

Revoking access and deletion

Access can be revoked at any time at myaccount.google.com/permissions. Revoking access and deleting the local token file removes all data the app holds. Locally stored API data (IDs of uploaded videos) is kept only to avoid duplicate uploads and is deleted automatically after 30 days, as required by the YouTube API Services Developer Policies. Deletion requests can also be sent through the contact below and are completed within 7 days.

Contact

Questions: open an issue at github.com/PaulChery/temny-apvout/issues or use the contact options on the YouTube channel “Тёмный Апвоут”.
